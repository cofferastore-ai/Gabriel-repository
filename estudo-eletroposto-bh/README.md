# Estudo de eletroposto em Belo Horizonte

Estudo de mercado e viabilidade (novembro de 2026) para abrir um ponto de recarga de carros elétricos em BH.

- `Estudo-Eletroposto-BH.pdf`: versão em PDF para os sócios.
- `index.html`: site completo e autocontido (abre direto no navegador, fotos embutidas).
- `site/artifact.html`: mesma página, no formato publicado como Artifact.
- `fotos/`: fotos dos locais e carregadores (Wikimedia Commons; créditos no próprio estudo).
- `build/`: `template.html` + `build.py` geram o site com os números do modelo financeiro (`python3 build/build.py`).
